# WedBar — мини приложение для моей свадьбы

Концепция простая. У моих гостей на свадьбе будут QR коды на столах, они смогут их отсканировать и попасть на это приложение. Там они смогут выбрать из нескольких коктейлей и заказкть то что понравится.

Сервис будет делится на 3 части:
- Бар — сервис для заказа коктейлей для гостей
- Панель заказов — список заказов для бармена (возможность принять заказ, выполнить, убрать позицию из меню)
- Админка — часть только для меня, там я смогу следить за заказами и какой-то статистикой

## ФТ:
### Бар
Пользователь сканирует QR код и пападает на страницу с меню напитков. Ему не нужно ничего дополнительно вводить, пользователя не нужно никак идентефицировать. Номер стола зашит в ссылке. 
Меню бара это лента в tiktok стиле, на каждый напиток отдается целая страница. Прежде всего изображение, делаем акцент на визуале, красивое изображение / видео напитка, название, небольшое описание, состав, кнопка заказать (1 нажатие и кнопка модифицируется в кнопку выбора количества + -). Когда в корзине > 1 напитка появляется кнопка для перехода в корзину. Корзина это отдельный экран: список напитков в заказе, кол-во с возможностью изменить + кнопка заказать (кнопка заказать как слайдер, нужно потянуть для заказа. Тут важно сразу проресерчить на accesability, если высоки риски, что могут быть ложные срабатывания / считываться как другой жест на мобильном, то лучше делать обычную). После того как заказ ушел, пользователь не может заказать повторно до момента доставки заказа (чисто клиент ограничение запись в local storage с id заказа и запрос сразу со всеми защитами, если заказ исполнен / ошибка удаляем запис и открываем меню). Экран ожидания заказа: список заказанных позиций + статус из 3 этапов (ожидает выполнения, выполняется, доставляем), из статуса доставляем заказ выходит сам по истечении времени (эвристика 5 минут), уже на статусе доставляем можно делать повторный заказ. История заказов показывается небольшими плашечками вверху экрана, по клику открывается экран заказа

### Панель заказов
6 карточек на весь экран без возможности скролла, каждая из них это заказ, заказы идут в порядке времени заказа, если прилетело более 6 заказов одновременно то следующий появится после выполнения какого-либо из предшествующих. Каждая карточка содержит стол к которому заказли (бармен исходя из этого клеит стикер, чтобы официант мог сориентироваться), напиток + миниатюру + кол-во, по клику на позицию открывается рецепт. Снизу карточки кнопка принять, которая переходит в кнопку готово при нажатии готово заказ пропадает с панели. Есть кнопка для открытия сайдбара, там открывается сайдбар 2 ссылки: панель заказов и настройки. В настройках можно отправить какую-то позицию в стоп и вернуть обратно

### Админка
Там можно добавить напитки, + небольшой дашборд со статистикой

## НФТ:
Возможность добавить каждую отдельную часть как PWA (bar pwa, панель заказов pwa, админка pwa)
Требования к безопасности невысокие, никакой авторизации, для бара главный экран + номер стола из query, для остальных честей рандомный роут, чтобы сложно было найти
